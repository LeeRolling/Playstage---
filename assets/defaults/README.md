# 默认图片放哪里

剧戏台的种子数据里已经写好了路径。仓库里不一定带着图片本身。把你电脑上的图按下面的相对路径放进这个文件夹，重新打开剧戏台就能看见。没有图也可以先用文字演戏。

夜晚图和白天图放在同一个地点文件夹里。种子数据默认把文件名里的 `_白天` 换成 `_晚上`。如果你的夜晚文件用的是 `_夜晚`，在世界书里把那一条的夜晚路径改成实际文件名即可。

路径相对于剧戏台文件夹，不要打成绝对路径。

## 角色全身图

放在 `assets/defaults/characters/女/` 下面：

- `北欧/Astrid.png`
- `北欧/Sigrid.png`
- `北欧/Elin.png`
- `东方/暖璃.png`
- `东方/月曈.png`
- `东方/清言.png`
- `现代/初棠.png`
- `现代/星璇.png`
- `现代/雪璟.png`

头像可以后裁。没裁之前，对话框左边会先用全身图。若你的文件是 jpg，到「人设」页把路径改成实际后缀，或另存为上面的 png 名字。
