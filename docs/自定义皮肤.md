# 自己改剧戏台的皮肤

剧戏台带了四套样子。你可以让它跟着舞台走，也可以一直用某一套。想微调颜色，改一个样式文件里的名字就行，不用先学写程序。

实在自己改不了，就让 AI 帮你。把 [皮肤制作-给AI.md](皮肤制作-给AI.md) 整篇交给它，或告诉它这个文件在项目里的位置。那一份是写给 AI 看的：变量在哪、四套皮肤怎么分、角花放哪、改完怎么保存刷新，以及哪些地方不能动。

## 四套现成的

| 你在界面上看到的 | 内部名字 | 什么时候出现 |
| --- | --- | --- |
| 经典 | `classic` | 还没选舞台，或你自己点了「经典」 |
| 东方 · 青玄 | `eastern` | 跟随舞台，并且当前是青玄界 |
| 赛博 · 霓穹 | `cyber` | 跟随舞台，并且当前是霓穹市 |
| 北欧 · 霜印 | `nordic` | 跟随舞台，并且当前是霜印王国 |

「经典」不会在选舞台时自动套上。它是默认样子，也是你可以手动选的一套。

## 跟随舞台，或自己指定

右侧「皮肤」里：

- **跟随舞台**：换舞台，样子跟着换。青玄界 → 东方，霓穹市 → 赛博，霜印王国 → 北欧。
- **点某一套的名字**：之后一直用这一套，换舞台也不改，直到你再点别的，或点回「跟随舞台」。

这个选择写在这台电脑的资料里（`data/library.json` 的 `settings`），关掉再打开还在。

两个字段：

| 字段 | 可以填的值 | 意思 |
| --- | --- | --- |
| `uiSkinMode` | `auto` 或 `manual` | `auto` 跟随舞台；`manual` 固定用下面那一套 |
| `uiSkin` | `classic`、`eastern`、`cyber`、`nordic` | 手动时用哪一套。跟随舞台时，这里仍记着你上次手选的名字，但台上先看舞台 |

不用手改这个文件。在界面里点，效果一样。

## 改颜色

1. 用记事本或任何文本编辑器打开 `src/ui/styles.css`。
2. 文件最上面、以 `--` 开头的那些名字，是「经典」用的。
3. 文件后部有三段，分别写着 `data-skin="eastern"`、`data-skin="cyber"`、`data-skin="nordic"`。要改哪一套，就改哪一段里面的名字。
4. 保存文件，回到浏览器，刷新页面。

每个名字管一块地方。颜色一般写成 `#` 加六位，例如 `#1a2332`。圆角写成数字加 `px`，例如 `4px`。`transparent` 表示完全透明。

| 名字 | 管什么 |
| --- | --- |
| `--bg` | 整页底色 |
| `--paper` | 平时的字 |
| `--paper-dim` | 次要的字 |
| `--muted` | 更淡的说明 |
| `--gold` | 强调色（链接、一些标题） |
| `--line` | 分割用的细线 |
| `--chrome` | 顶栏 |
| `--rail` | 左侧功能条 |
| `--side` | 右侧这一栏 |
| `--stage-wash` | 还没放背景图时，舞台本身的底色 |
| `--dialog-bg` | 对话框的底 |
| `--dialog-ink` | 对话框里的字 |
| `--dialog-muted` | 对话框里比较淡的字 |
| `--dialog-border` | 对话框的边 |
| `--name-ink` | 说话人名字的字色 |
| `--name-chip` | 名字后面的色块。不需要色块就写 `transparent` |
| `--button-bg` | 按钮的底 |
| `--button-ink` | 按钮上的字 |
| `--button-border` | 按钮描边。不需要描边可以写 `transparent`，并把 `--button-border-width` 写成 `0px` |
| `--ledger-bg` / `--ledger-ink` | 「世界」「人设」这些内页的底和字 |
| `--modal-bg` / `--modal-ink` | 弹出来的窗口 |
| `--radius-dialog` | 对话框圆角。数字小就更方 |
| `--radius-button` | 按钮圆角 |
| `--frame` | 边框粗细 |

改的时候只改冒号右边，左边的名字别动，也别删掉行末的分号。

说话时，没开口的立绘会变暗；背景图保持原来的亮度。这两件事不跟皮肤走，改上面的颜色不会把它们关掉。

## 自己的角花图（可选）

这一版的边角花纹是样式画出来的，不附带图片，也可以直接用。

如果以后想换成自己的图：

1. 在 `assets` 里建文件夹，名字用皮肤的内部名字，例如 `assets/skins/eastern/`。赛博是 `cyber`，北欧是 `nordic`。
2. 把角花放进去，文件名自定，例如 `corner.svg` 或 `corner.png`。小图即可，建议方的、底透明。
3. 打开 `src/ui/styles.css`，找到对应的 `data-skin` 那一段里的 `--corner-marks:`。
4. 在这一行原来的内容最前面加上图片地址，并留一个逗号。例如东方那一套，改成以这句开头：

```css
--corner-marks: url("/assets/skins/eastern/corner.svg"),
```

后面原来的那些线条保留也行，它们会和你的图叠在一起。若只想看见自己的图，把逗号后面、直到分号之前的内容删掉，只留这一句 `url(...)`。

5. 保存，刷新页面。

图片只放在你自己的电脑上，剧戏台不会上传。

交给 AI 改角花或颜色时，用 [皮肤制作-给AI.md](皮肤制作-给AI.md)，不要只把这一页贴过去。这一页是给人看的步骤；那一页写了选择器和不能改的地方。
