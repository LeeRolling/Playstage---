# 动作与表情

人设页里，每位角色的【动作与表情】只给这一位配图。点返回会回到刚才那张人设卡。

这些图是给台上切换表情和动作用的。点缩略图可以看大图。台上现在仍默认用全身图。

## 文件夹

新裁的表情、动作写进角色名字下的文件夹。不搬动、也不删除原来的图。

- `assets/characters/角色名/立绘/`：留给全身图和思考图。这一版不强制把旧图搬进来。
- `assets/characters/角色名/表情/`：新的表情。
- `assets/characters/角色名/动作/`：新的动作。

例如：`assets/characters/暖璃/表情/expr_smile.png`，`assets/characters/暖璃/动作/pose_wave.png`。

原来的单文件还能用，比如 `assets/defaults/characters/女/东方/暖璃.png`，或 `data/media/` 里已经裁好的图。后缀写错、文件夹差一点时，仍按同名图片自己对上。

`assets/characters/` 里是你自己的图。更新不会替换它们，也不会写进程序清单。

文件名用下面的固定编号，不用中文情绪词。界面上的短中文只是给人看的。
