# 剧戏台

剧戏台是装在你自己电脑上的多角色文字演戏工具。你准备世界和角色，在一块深色的戏台上跟他们说话。故事存在这台电脑里。

这一版能开场：先选一座舞台，再跟那三位说话。台上的回复来自你在「模型」里选中的本机 Ollama，或智谱、通义千问。软件本身不带模型。

三座舞台不会挤在同一场里。

- 霜印王国：Astrid、Sigrid、Elin
- 青玄界：暖璃、月曈、清言
- 霓穹市：初棠、星璇、雪璟

每本世界书写了氛围、冲突和禁忌，也写好了地点图的路径。图片如果还没放进文件夹，戏台会告诉你路径在，图还不在。怎么摆放见 [assets/defaults/README.md](assets/defaults/README.md)。

## 怎么打开

需要先安装 [Node.js](https://nodejs.org/)（建议 20 或更新的版本）。**这一步要你自己完成**，只做一次。剧戏台不附带 Node，也不附带 AI 模型。

Windows：

1. 进入解压后的文件夹。
2. 双击 `start.bat`。
3. 浏览器若没有自己弹出，请打开：<http://127.0.0.1:4173>
4. 第一次会有一段新手引导。看完并勾选免责声明后进入戏台。
5. 关掉黑色窗口，剧戏台就停止。

Mac 或 Linux：在这个文件夹打开终端，输入 `bash start.sh`，再用浏览器打开上面的地址。也可以输入 `npm start`，效果一样。

## 模型要你自己准备

剧戏台**只提供软件，不提供、也不下载模型**。上台之后，角色的话来自你选中的那一家。

### 本机 Qwen（Ollama）

这一步要你自己做。

1. 安装并打开 [Ollama](https://ollama.com/)。
2. 在 Ollama 里装好你要用的模型，例如本地的 Qwen。只建议从官方渠道拿官方开源模型。
3. 打开剧戏台，进入左侧「模型」。
4. 选「用这台电脑演戏」。本机地址一般是 `http://127.0.0.1:11434`，写成 `http://127.0.0.1:11434/v1` 也可以。
5. 点「读取本机模型」，在列表里选中你刚装的那个，再点「保存设置」。
6. 回到「演戏」，写一句，点「送上台」。

Ollama 没打开时，戏台会用中文告诉你连不上，不会把页面弄崩。

### 智谱、通义千问

钥匙只写在这台电脑的 `data/library.json` 里，不要发给别人，也不会进仓库。

1. 智谱：到智谱开放平台自己申请钥匙。模型名常见是 `glm-4-flash`。地址已经填好，不用改。
2. 通义千问：到阿里云百炼自己申请钥匙。模型名常见是 `qwen-plus`。地址已经填好。
3. 在「模型」页选「用智谱演戏」或「用通义千问演戏」，粘贴钥匙和模型名，点「保存设置」，再点对应的「测试」。
4. 回到戏台送一句。钥匙不对、或请求太频繁，都会有一句中文提示。

- 不知道显卡能不能跑：打开 <https://www.canirun.ai/models> 自己查。大约 8GB 显存通常有合适的文本模型方向；大约 4GB 也有更轻的模型，但体验有限。查不到合适的也不用着急。

## 免责声明

剧戏台只提供这套软件，不提供、也不附带任何 AI 模型。模型从哪里下载、能不能用，由你自己负责。我们只建议到模型官方渠道下载官方开源模型。成人或敏感内容取决于你选用的模型和你自己的判断，软件不会承诺「已经替你审查过模型」。

## 我的东西在哪

世界书、人设、会话和存档写在文件夹 `data/library.json`。拷走整个 `data` 文件夹就是备份。没有账号，也没有云存档。请不要把这个文件发给不信任的人，里面可能有你填写的云端钥匙。

## 这一版里有什么

- 第一次进来先选舞台。一场戏只挂一本世界书，只请这一岸的三位。
- 戏台：人物立绘站在半透明对话框后面；对话框左侧是当前说话人的头像。设了背景图之后，不再挡上默认的幕布。
- 提到地点名字，背景会跟着换。白天和夜晚可以切。特殊情景如果还没配图，会先沿用地点背景。
- 世界书里可以自己加地点，头像、全身图和地点图都可以裁一下再保存。
- 人设卡写好了默认全身图的路径。图放进 `assets/defaults` 才会显示。
- 会话：两位及以上角色是群聊，只留一位是一对一。
- 存档、导入导出的入口（导出为占位文件，导入只登记）。
- 模型页：可选本机 Ollama、智谱、通义千问，或另一家 OpenAI 兼容地址。读到本机模型列表后可以点选。钥匙只留在这台电脑。下次打开会提醒再测一次本机连接。按角色分家的接口先留着，这一版全场只用你选中的那一家。抢话一轮最多接两句，然后进入冷静，避免互相刷屏。
- 新手引导会看 Node（能打开页面就算通过）和 Ollama 通不通。Ollama 没开也不挡你选舞台。
- 四套界面皮肤：经典、东方 · 青玄、赛博 · 霓穹、北欧 · 霜印。选舞台时若是「跟随舞台」，会自动换成那一座的样子。在右侧点某一套，就会固定下来。这个选择在 `settings.uiSkin`（`classic` / `eastern` / `cyber` / `nordic`）和 `settings.uiSkinMode`（`auto` 跟随舞台，`manual` 固定）。怎么自己改颜色，见 [docs/自定义皮肤.md](docs/自定义皮肤.md)。

若你之前已经打开过旧的试演，`data/library.json` 会在下次启动时换成这三座舞台，并尽量留下免责声明和已经填过的模型地址、钥匙。旧的「空台」对话不会跟着迁过来。想完全重来，把 `data/library.json` 挪走再启动即可。种子内容也写在 `data/library.seed.json`。

## 给以后看代码的人

界面在 `src/ui`，只通过本机网页接口说话。世界书、人设、会话、存档这些规则在 `src/domain`，不引用界面。`src/server` 负责把两边接上。改外观时不要把规则写进页面；改规则时不要去改画布。

检查：`npm test`，以及 `npm run check`。

## 许可证与仓库

仓库目前保持**私有**。产品方向是以后公开源码；公开前再选定许可证（候选 MIT）。开源的是软件，不是你的世界书、存档或钥匙。
