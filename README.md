# 剧戏台

**在自己的电脑上搭一个小戏台，和 AI 角色一起聊天、演故事。**

#起因#
是因为酒馆SillyTavern这类实在是太复杂了。我一怒之下怒了一下。然后自己弄了一个UI更简单的酒馆类软件。玩法和SillyTavern没有什么区别。支持本地AI大模型和API。

---
你可以把它想成一场文字版的过家家：先选故事发生的地方，再告诉角色“你是谁、是什么性格”，然后说一句话，等他们接着演。

剧戏台是一款**在本机运行的多角色 AI 文字演戏工具**。它提供深色的戏台界面、世界书、角色设定和会话管理。你负责准备 AI 模型，模型负责让角色接话。

- **没有账号，也没有云同步。** 世界书、角色、会话和存档保存在你的电脑里。
- **模型由你选择。** 可以接本机 Ollama，也可以接智谱、通义千问或其他 OpenAI 兼容的云端服务。
- **软件不附带 AI 模型，也不提供模型下载地址。** 需要你自己准备。

这里说的“存档在本机”，指的是文件保存的位置。**选择云端模型接话时，请求会发送给你选择的云端服务。**

## 一共分 3 步启动

### 第 1 步：装好 Node.js

先安装 [Node.js](https://nodejs.org/)，**建议使用 20 或更新的版本**。

它是让剧戏台运行起来的工具，自己安装一次就行。剧戏台不附带 Node.js，也不附带 AI 模型。安装 Node.js 时通常也会装好 `npm`（管理程序依赖的工具），后面启动、检查程序时会用到它。

#### Windows：先打开输入命令的窗口

1. 找到键盘上的 **Windows 键**，常写成 **Win 键**。它上面画着 Windows 的窗户标志，一般在键盘左下方的 `Ctrl`（控制键） 和 `Alt`（换档键） 之间。有些键盘的位置会不同，认准标志就行。
2. **按住 Win 键，再按一下字母 R，最后松开两只手。** 这就是 `Win + R` 组合按键。
3. 按完 `Win + R` 之后，一般情况下，屏幕的左下角会出现一个叫「运行」的小窗口。
4. 我们在这个「运行」的小窗口里面，在输入框里输入 `cmd` 这三个字母即可，然后点「确定」，或者按回车键 `Enter`（回车键）。
5. 会出现一个可以输入文字的命令窗口，通常是黑色的。下面的命令都粘贴到这里，每次输入后按回车。**不要粘贴到聊天框或浏览器地址栏。**

先检查自己是不是已经装好了，分别输入：

```bat
node -v
```

```bat
npm -v
```

如果第一条显示 `v20`、`v22`、`v24` 等以 `v` 开头的版本号，并且主版本号是 **20 或更高**，第二条也显示版本号，就可以直接继续「第 2 步：打开剧戏台」。`npm` 的版本号不需要达到 20。

如果提示「不是内部或外部命令」，或者 Node.js 版本低于 20，再用下面任意一种方法安装。

#### Windows 方法 A：一条命令安装

Windows 10 / 11 上，如果可以使用微软的 WinGet（Windows 程序包管理器；这是一个工具的名称，具体指令见下方），就能让它帮你下载并安装 Node.js 的 **LTS（长期支持）版**。LTS 可以理解成“长期维护、适合日常使用的版本”。

在刚才的'cmd'命令窗口里粘贴这一整行，再按回车：

```bat
winget install --id OpenJS.NodeJS.LTS --exact --source winget --interactive
```

等它下载完，然后按安装窗口里的提示继续。如果出现许可条款，阅读后决定是否接受；如果 Windows 问「是否允许此应用对你的设备进行更改」，确认是本次 Node.js 安装后，点「是」。整个过程需要联网，下载时请耐心等一会儿。

**更省事的双击方式：** 如果你同时拿到了本文配套的 [install-node.bat](install-node.bat)，可以双击它。它会先检查已有的 Node.js；版本够用就跳过，否则调用同一条 WinGet 安装命令。许可条款和系统确认仍需要你自己点击。

这个 `.bat` 是本文附带的安装辅助文件，需要和 README 一起提供；它不是原仓库已经具备的功能，也不包含 Node.js 安装包。

提示找不到 `winget`、下载失败或无法完成安装时，直接使用下面的官网安装方法。WinGet 的命令参数见 [微软官方安装说明](https://learn.microsoft.com/en-us/windows/package-manager/winget/install)。

#### Windows 方法 B：从官网下载，一步一步点击

1. 打开浏览器，进入 [Node.js 官方下载页](https://nodejs.org/en/download)。
2. 选择 **LTS（长期支持）** 版本，确认主版本号为 **20 或更高**。
3. 系统选 **Windows**。大多数 Intel / AMD 电脑选 **x64（常见的 64 位处理器架构）**；使用 ARM 处理器的电脑选 **ARM64（64 位 ARM 处理器架构）**。不确定时，打开 Windows「设置 → 系统 → 关于」，看「系统类型」。
4. 选择 **Windows Installer（Windows 安装程序，文件后缀为 `.msi`）**，下载安装文件。官网排版和按钮文字可能随版本调整，认准 Windows、LTS 和 `.msi` 即可。
5. 下载完成后，打开浏览器下载列表，或进入电脑的「下载」文件夹，双击刚下载的 `.msi` 文件。
6. 安装窗口打开后，点 **Next（下一步）**。
7. 阅读许可条款；同意后勾选 **I accept…（我接受…）**，再点 **Next（下一步）**。
8. 安装位置保持默认，点 **Next（下一步）**。组件选择也保持默认，保留 **npm（管理程序依赖的工具）** 和 **Add to PATH（添加到命令搜索路径）**。后者让电脑能找到 `node`、`npm` 命令。
9. 如果出现额外的原生模块工具安装选项，首次按本文启动剧戏台可以先保持不勾选；如后续依赖明确要求，再按对应说明安装。
10. 点 **Install（安装）**。如果 Windows 弹出系统确认，确认是这次 Node.js 安装后点「是」。
11. 等待安装完成，点 **Finish（完成）**。

#### 安装后，确认真的装好了

**关掉刚才的命令窗口，再按 `Win + R`，输入 `cmd`，打开一个新窗口。** 旧窗口可能还不知道你刚装了新工具。

再次分别输入 `node -v` 和 `npm -v`。两条都能显示版本号，并且 Node.js 主版本号为 20 或更高，就可以启动剧戏台了。

| 遇到的情况 | 怎么处理 |
| --- | --- |
| 安装后仍提示找不到命令 | 先关掉旧命令窗口，重新打开；仍不行就重启电脑，再检查一次 |
| 重启后仍找不到命令 | 重新运行官网安装程序，检查是否保留了 `Add to PATH`（添加到命令搜索路径） 和 npm 组件 |
| Node.js 显示旧版本 | 关闭窗口重试；若仍低于 20，可能有多个安装版本，需要先处理旧版本或旧路径 |
| 在 PowerShell（Windows 命令工具）输入 `npm` 时提示脚本禁止运行 | 按上面的 `Win + R → cmd` 打开命令提示符再试，无需为了本教程修改系统脚本策略 |

#### Mac / Linux

Mac 用户在 [Node.js 官方下载页](https://nodejs.org/en/download)选择合适架构的 LTS（长期支持）版 macOS 安装程序（`.pkg`），双击后按提示继续安装。

Linux 用户按官网提供、适合自己发行版的安装方式安装 LTS（长期支持）版。确认主版本号为 20 或更高；不同发行版步骤不同，不要直接照搬 Windows 命令。

安装完成后，重新打开终端，分别执行 `node -v` 和 `npm -v`。两条都显示版本号、Node.js 主版本号为 20 或更高，再继续启动剧戏台。

## 接好模型，让角色开口

剧戏台是戏台，AI 模型是负责接话的“演员大脑”。软件本身不提供模型，角色的回复来自你在「模型」页选中的服务。

### 使用本机 Ollama

先记住三件不同的事：**Ollama 装好了、模型下载好了、模型正在加载使用中**。它们不是同一步。就像厨房建好了，不代表食材已经买来；食材买来了，也不代表饭已经做好。

本地大语言模型需要自己准备，例如 Qwen（通义千问）的开源文本模型。我们建议只从官方渠道下载官方开源模型。**下载到电脑上的模型文件，还需要按对应格式导入或安装到 Ollama；不能只放进剧戏台的文件夹就使用。**

下面先在 Ollama 里检查，再连接剧戏台。命令可参考 [Ollama 官方命令说明](https://docs.ollama.com/cli)。

#### 第 1 步：安装并打开 Ollama

安装 Ollama 后，Windows 用户从开始菜单打开 Ollama；Mac 用户打开 Ollama 应用。使用期间，让它保持运行。

接下来打开一个输入命令的窗口：

- **Windows**：在开始菜单搜索 `PowerShell`（Windows 命令工具），打开它。或者按 Win + X，在弹出的对话框中，选择‘终端（管理员）’
- **Mac / Linux**：打开「终端」。

下文的命令都输入在这个窗口里，输完按回车，**不要输入到浏览器地址栏或剧戏台聊天框里**。这些 Ollama 检查命令不要求你进入剧戏台文件夹。

#### 第 2 步：确认 Ollama 能连接，模型已装好

输入：

```bash
ollama ls
```

你会看到模型列表，通常有 `NAME`（名称）、`ID`（标识编号）、`SIZE`（大小）、`MODIFIED`（最后修改时间） 等列。重点看 `NAME`（名称）：它是后面运行、选择模型时要用的完整名字。

- **出现模型名字**：Ollama 能连接，而且这些模型已经安装。
- **只有表头，没有模型**：Ollama 能连接，但还没有装好可列出的模型。先按模型官方和 Ollama 的说明准备模型，再检查一次。
- **提示连接失败，例如 `could not connect to Ollama`（无法连接到 Ollama）**：Ollama 服务还没启动，或当前连接地址有问题。先重新打开 Ollama。
- **提示找不到 `ollama` 命令**：先确认 Ollama 已安装，再关闭这个命令窗口，重新打开后重试。

如果你通过命令行运行 Ollama，并且服务确实没有启动，可以在另一个终端窗口输入：

```bash
ollama serve
```

让这个服务窗口保持打开，再回到原来的窗口执行 `ollama ls`。已经能连接时，就不用重复执行 `ollama serve`；提示地址或端口已被占用时，可能已经有一个 Ollama 服务在运行。

**在 `ollama ls` 中看到模型，只表示“模型已经装好”，还不能证明它正在内存或显存里运行。**

#### 第 3 步：先让模型回答一句话

从 `ollama ls` 的 `NAME`（名称） 列复制你要用的完整模型名，包括冒号后面的版本标记。

输入下面的命令，先把 `你的模型名` 换成刚才复制的名字：

```bash
ollama run 你的模型名 "请用中文说一句你好。"
```

**不要原样输入“你的模型名”。** 例如，列表里显示 `qwen2.5:7b` 时，对应命令是：

```bash
ollama run qwen2.5:7b "请用中文说一句你好。"
```

这里的名字只是示例，不表示你的电脑已经安装了它，也不保证它适合你的电脑。使用自己列表中已有的本地文本对话模型；使用本机地址连接 Ollama 时，也要确认所选模型是在本地运行的模型。

第一次接话需要把模型加载进来，可能要等一会儿。**看到它真的回了一句话，就说明这次模型能正常接话。**

如果出现下载进度，先检查模型名是否和列表完全一致：指定的模型不在本机时，`ollama run` 可能会尝试下载它。若出现内存不足或加载失败，先让这个模型在 Ollama 中成功回答，再连接剧戏台。

#### 第 4 步：确认模型现在已经加载

模型刚回答完时，立即输入：

```bash
ollama ps
```

**列表里出现你刚用的模型名，才表示它目前已加载在内存或显存中。** 如果只有表头，表示当前没有已加载的模型；它可能还没有被调用，也可能空闲后已经卸下，并不代表模型文件被删了。

想知道它有没有用上显卡，看 `PROCESSOR`（处理器） 列：

| 显示内容 | 意思 |
| --- | --- |
| `100% GPU`（全部使用图形处理器，也就是显卡） | 模型全部加载在显卡中 |
| `100% CPU`（全部使用中央处理器） | 模型全部加载在系统内存中，使用 CPU（中央处理器） |
| 同时出现 CPU（中央处理器）和 GPU（图形处理器） 的百分比 | 模型分别加载在系统内存和显卡中 |

`UNTIL`（保留截止时间） 列表示当前预计会保留到什么时候。Ollama 默认会在模型空闲约 5 分钟后卸下，具体时间可被设置或调用请求改变；剧戏台的「预热加载」另有自己的保留策略，见下文。

加载状态、GPU（图形处理器）/ CPU（中央处理器） 显示和空闲卸载说明见 [Ollama 官方常见问题](https://docs.ollama.com/faq)。**能列出模型、能加载模型、模型能正常回答，是三个分别要确认的结果。**

#### 第 5 步：在剧戏台里选中这个模型

1. 打开剧戏台，在左侧边栏进入「模型」。
2. 本机地址一般填 `http://127.0.0.1:11434`，写成 `http://127.0.0.1:11434/v1` 也可以。**这里是 Ollama 的地址；剧戏台网页用的是 `4173`，不要把两者填反。**
3. 点「读取本机模型」，选择刚才在 Ollama 中测试成功的模型，确认完整名字一致。
4. 第一次测试时，建议暂时选「只用本机」，再点「保存设置」。这样本机接不上时会直接提示，方便确认问题，不会因为自动改用云端而误以为本机已成功。
5. 回到「演戏」，写一句“你好，请用中文介绍一下自己”，点「送上台」。
6. 查看是否收到回复和本次使用的服务提示；接话后也可以立即运行 `ollama ps`，检查所选模型是否已经加载。

测试成功后，可以把接话方式改回「自动：本机优先，否则用云端」，再保存设置。选「不选本机模型」会清掉本机模型名。

**日常使用时，不必每次都先运行 `ollama run`。** 只要 Ollama 服务开着、模型已装好，并且剧戏台选对了模型，剧戏台发出请求时就可以让 Ollama 加载它。上面的命令主要用来逐步确认哪里正常、哪里出了问题。

#### 卡住了，先查哪里？

| 遇到的情况 | 先这样检查 |
| --- | --- |
| 剧戏台读不到本机模型 | 先执行 `ollama ls`；能列出模型后，检查剧戏台本机地址是否为 `http://127.0.0.1:11434`，再重新读取 |
| `ollama ls` 有模型，`ollama ps` 没有 | 已安装但当前没加载；先让它回答一句，或在剧戏台点「现在预热」，再立即查看 |
| 命令行能回答，剧戏台不能回答 | 核对地址、完整模型名和「保存设置」，用「只用本机」重试，并查看中文错误提示 |
| 角色回答了，但想确认是不是本机 | 查看本次服务提示，使用「只用本机」重新测试；只看到回复不能证明用的是本机 |
| 加载时提示内存不足 | 换更轻的本地模型、关闭占用内存或显存的其他程序后再试；也可以改用云端 |
| `PROCESSOR`（处理器） 显示 CPU（中央处理器），回复比较慢 | 说明当前模型使用 CPU（中央处理器）；显卡是否受支持、驱动是否正常，需要按 Ollama 的硬件说明检查 |

#### 本机接不上，会怎么样？

如果 Ollama 没打开、模型没装好，或本机模型名被清掉了，**自动模式会尝试改用已经配置好的云端模型**。前提是智谱、通义千问或「另一家云端」（例如 DeepSeek）已经填好钥匙和模型名。界面会告诉你，这一句用了哪一家。

选择「只用本机」时，程序会停下来，提示你回去选择本机模型。

#### 想少等一会儿：预热加载

勾选「预热加载」，再点「现在预热」，选中的本机模型会留在显存里，减少每说一句话就重新加载、再卸下的等待。

- 大约 **10 分钟**没有用本机接话，显存会被释放。
- 点「卸下」，也会释放显存。
- 取消「预热加载」并保存设置，也会卸下模型。
- 自动改用云端时，云端请求不会带上预热设置；本机占用的显存仍会在空闲后释放。

### 使用云端模型

可以使用智谱、通义千问，或在「另一家云端」中配置 OpenAI 兼容地址，例如 DeepSeek（深度求索）、月之暗面 Kimi 等。

“API Key（接口密钥）”就是调用云端模型的钥匙。**它只保存在这台电脑的 `data/library.json` 中，不要发给别人，也不要公开。**

| 服务 | 需要准备什么 |
| --- | --- |
| 智谱 | 到智谱开放平台申请 API Key（接口密钥）。常见模型名是 `glm-4-flash`。服务地址已预填，通常不用改 |
| 通义千问 | 到阿里云百炼申请 API Key（接口密钥）。常见模型名是 `qwen-plus`。服务地址已预填 |
| 另一家云端 | 填写对应服务的 OpenAI 兼容地址、API Key（接口密钥） 和模型名 |

设置方法：

1. 进入「模型」页，勾选「云端优先用智谱」或「云端优先用通义千问」，填好钥匙和模型名。其他服务填在「另一家云端」。
2. 接话方式选择「自动」或「只用云端」。
3. 点「保存设置」，再点对应服务的「测试」。
4. 回到戏台，发一句话试试。

API Key（接口密钥） 不正确或请求太频繁时，对话框界面会给出中文提示。

**自动模式下，只要本机模型能接话，仍会先用本机。**「云端优先用智谱／通义千问」决定的是使用云端时的优先选择。

### 不知道电脑能跑什么模型？

可以到 <https://www.canirun.ai/models> 查询。

大约 8GB 显存通常有合适的文本模型可选；大约 4GB 也有更轻的模型，但体验有限。这不是运行效果的保证。找不到合适的本机模型，也可以使用云端模型。

## 我的故事存在哪里？

世界书、角色设定、会话和存档保存在：

```text
data/library.json
```

存档、云端钥匙和自己的图片都保存在 `data/` 文件夹里。**复制整个 `data/` 文件夹，就是备份。** 请妥善保管：这里没有账号，也没有云存档或云同步。

**不要把 `data/library.json` 发给任何人，包括你信任的人。** 它里面可能有你填写的云端 API Key（接口密钥）。备份整个 `data/` 文件夹时，也要按含有钥匙的私人文件保管。

### 旧版数据与重新开始

如果你用过旧的试演版本，下次启动时，`data/library.json` 会自动迁移到三座舞台的格式，并尽量保留免责声明确认状态，以及已填写的模型地址和钥匙。

**旧版「空台」里的对话不会迁移过来。**

想完全重新开始，可以先备份，再把 `data/library.json` 挪走，然后启动程序。种子内容也保存在 `data/library.seed.json` 中。

## 目前可以怎么玩？

### 聊天与演戏

- **选舞台开始**：第一次进入时先选舞台，一场戏使用一本世界书。
- **群聊或一对一**：两位及以上角色是群聊；只留一位角色，就是一对一。
- **限制连续抢话**：抢话一轮最多接两句，随后进入冷静期，避免角色互相刷屏。
- **选择接话模型**：支持本机 Ollama、智谱、通义千问，以及另一家 OpenAI 兼容服务。读取本机模型列表后，可以直接点选。下次打开时，会提醒你再测一次本机连接。

### 人物与背景

- **戏台画面**：人物立绘站在半透明对话框后面，当前说话人的头像显示在对话框左侧。设置背景图后，默认幕布就不再遮挡背景。
- **地点换背景**：对话中提到地点名字，背景会跟着切换。可以切换白天和夜晚；特殊情景还没配图时，会先沿用地点背景。
- **自己加地点和图片**：可以在世界书里添加地点。头像、全身图和地点图都可以裁剪后保存。
- **默认全身图**：角色卡已写好默认全身图路径，把对应图片放进 `assets/defaults` 才会显示。
- **等待时的「思考」图**：可以给角色另设一张「思考」全身图。该角色等待模型回复时，舞台切换到这张图；回复结束后切回原来的全身图。没设置就不切换。
- **动作与表情素材**：角色卡的【动作与表情】可以为该角色配置十张表情、十一张动作。新图写入 `assets/characters/角色名/表情` 和 `assets/characters/角色名/动作`。舞台目前仍使用全身图，**模型说话时自动切换动作、表情图片的功能还没完成**。详见 [动作与表情说明](docs/动作与表情.md)。

### 四套界面皮肤

目前有四套：**经典、东方 · 青玄、赛博 · 霓穹、北欧 · 霜印**。

选择「跟随舞台」时，换舞台会自动换成对应皮肤。在右侧点选某一套皮肤后，就会固定使用它。

想自己改颜色，可以看 [自定义皮肤说明](docs/自定义皮肤.md)。对应设置为：

| 设置项 | 可选值 |
| --- | --- |
| `settings.uiSkin`（界面皮肤设置） | `classic`（经典） / `eastern`（东方） / `cyber`（赛博） / `nordic`（北欧） |
| `settings.uiSkinMode`（界面皮肤模式） | `auto`（自动）：跟随舞台；`manual`（手动）：固定皮肤 |

## 检查与更新

### 想确认程序是否正常？

| 系统 | 检查方法 |
| --- | --- |
| Windows | 双击 `check.bat` |
| Mac / Linux | 在项目文件夹运行 `npm run check` |

通过后，窗口会显示「检查通过」。如果没通过，先把窗口里的文字截图保存，别急着更新。

### 更新会动我的存档吗？

启动时，如果能连接 GitHub，程序会对照公开仓库 `main`（主分支）里的 `VERSION`（版本号文件）。发现新版本后，只替换程序文件，**不会改动 `data/` 中的存档、云端钥匙和自己的图片**。

以下情况会直接用当前版本启动，不影响继续演戏：

- 无法连接 GitHub。
- 没有读取权限。
- 你放置了 `data/skip-update.txt`。

请仍然妥善保管自己的 `data/` 文件夹。

## 给开发者：界面和规则分开

代码分为三部分：

| 路径 | 负责什么 |
| --- | --- |
| `src/ui` | 界面，只通过本机网页接口通信 |
| `src/domain` | 世界书、角色设定、会话和存档等规则，不引用界面 |
| `src/server` | 连接界面和规则 |

**改外观时，不要把规则写进页面；改规则时，不要去改画布。**

检查方式：双击 `check.bat`，或在项目文件夹运行：

```bash
npm run check
```

发布内测版本前，先通过检查，再修改版本号和更新清单。
